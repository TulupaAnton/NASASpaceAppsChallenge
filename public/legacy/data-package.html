Current integration

The current model weighs climate and cooling (25%), renewable energy (60%), and water resources (15%). The data come from NASA POWER, DTU Global Wind Atlas, Copernicus DEM, and GloFAS. The water indicators estimate nearby sources and streamflow.

Regional scores compare 19 reference sites. The map uses a region’s reference site when an exact point analysis is unavailable. The score supports site screening. A project decision also needs confirmation of grid capacity, water access, network connectivity, and permitting.
